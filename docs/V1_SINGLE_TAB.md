# V1：Edge 单标签页工作文件

状态：`in_progress`

## 目标

在一个已绑定的 ChatGPT 标签页上完成：

```text
Codex MCP 调用
  -> Bridge 排队
  -> Edge 扩展发送到页面
  -> 读取 Assistant 完成内容
  -> Bridge 保存消息
  -> MCP 返回结构化结果
```

## 不包含范围

- 多标签页并发。
- 多人格自动编排。
- 远程访问。
- ChatGPT 内部接口调用。
- 全量历史聊天抓取。
- 托盘程序和安装器。

## 验收标准

1. MCP 能够查询 Bridge、扩展和页面状态。
2. MCP 能够向绑定标签页发送一条消息。
3. 能够返回完整 Assistant 文本，而不是流式中间片段。
4. 页面新增消息能通过游标读取。
5. 同一个请求不会因重试产生重复消息。
6. Bridge 或扩展断开后，任务会明确失败并可重新执行。
7. 所有运行文件都留在项目根目录内。

## 关键设计提醒

- 默认保持当前 ChatGPT 会话，不强制每次刷新页面。
- 同一标签页严格串行，不接受并发请求。
- DOM 选择器只存在于扩展适配器。
- 不把完整聊天正文写入普通运行日志。
- 先保证文本闭环，再扩展图片、文件和复杂 UI 操作。
