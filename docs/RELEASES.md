# 版本与发布

## 版本规则

从 **1.0.0** 开始，普通交付递增中间位，小补丁递增最后一位。

| 改动 | 示例 | 命令 |
|---|---|---|
| 普通功能、修复或调整 | 1.0.0 → 1.1.0；1.1.2 → 1.2.0 | `python scripts/bump_version.py minor` |
| 临时纠错、小补丁 | 1.0.0 → 1.0.1 | `python scripts/bump_version.py patch` |
| 检查 | 四处版本一致、格式合法 | `python scripts/bump_version.py --check` |

同一批改动只升一次版本。源码、扩展 Manifest、Python 包与托盘程序保持一致；发布对应 Git 标签 `vX.Y.Z`。安装包和缓存不进入 Git。

真实会话 URL、聊天问答、浏览器与机器诊断证据仅保留本机，不随公开源码发布。

## 1.1.0 — 2026-11-04

- 项目更名 AI-Web-MCP，Python 模块 ai_web_mcp、Windows 托盘 AI Web MCP、统一技能 ai-web-mcp。
- 新增 GLM 网页文本和图片能力，支持新聊天与指定 cid URL；原 ChatGPT 文本和图片能力保留。
- MCP 与统一 CLI 共用 provider 选择、目标核验、任务队列及恢复规则。
- 新增独立图片上传、消费已有附件发送；保留图文一体便捷接口。
- GLM 使用目标页面 paste 事件接入图片，不操作系统剪贴板；默认图片候选和普通发送均单次真实点击。
- 思考区与最终回答分离，依据真实停止图标判定生成状态；本地历史同步只采集已渲染问答。
- 统一多目标歧义与提供方冲突处理；文本可按显式任务 ID 恢复；附件 receipt 与新会话世代防止误用缓存。
- 旧 GPT 模块、工具与安装路径保留兼容入口，避免既有 Agent 配置失效。

真实会话及实机证据保存在本机 data 目录，不进入公开仓库。
