# 版本与发布

## 版本规则

从 **1.0.0** 开始，普通交付递增中间位，小补丁递增最后一位。

| 改动 | 示例 | 命令 |
|---|---|---|
| 普通功能、修复或调整 | 1.0.0 → 1.1.0；1.1.2 → 1.2.0 | `python scripts/bump_version.py minor` |
| 临时纠错、小补丁 | 1.0.0 → 1.0.1 | `python scripts/bump_version.py patch` |
| 检查 | 四处版本一致、格式合法 | `python scripts/bump_version.py --check` |

同一批改动只升一次版本。源码、扩展 Manifest、Python 包与托盘程序保持一致；发布对应 Git 标签 `vX.Y.Z`。安装包和缓存不进入 Git。
